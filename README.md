# الأكاديمية الذكية – الهلال الأحمر لمحافظة الرمح

**الرابط المباشر للموقع:** <https://oaalo.github.io/ramah/>

المستودع: <https://github.com/oaalo/ramah>

> أي تعديل ترفعه على فرع `main` يظهر تلقائياً على الموقع خلال دقيقة تقريباً.

موقع تعريفي وتدريبي (HTML/CSS/JS ثابت بدون أي أدوات بناء) يحتوي على:

- الصفحة الرئيسية مع الأقسام: القوانين، التوظيف، الدورات، المكافآت
- صفحات محتوى داخلية: `laws-content.html`، `job-content.html`، `careers-content.html`، `rewards-content.html`
- سلايدات الدورات: `guide.html`، `operations.html`، `supervisor.html`، `air-support.html`
- شعار المحافظة: `logo.svg`
- صفحة `404.html` تعمل مع الروابط النظيفة (مثل `/laws`) عبر GitHub Pages

## المعاينة محلياً

```bash
python -m http.server 8123
```

ثم افتح: <http://127.0.0.1:8123/>

> للروابط النظيفة مثل `/laws` لا بد من استضافة تدعم `404.html` (GitHub Pages تدعمها تلقائياً).

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً (Public) على GitHub.
2. ارفع الملفات:

```bash
git init
git add .
git commit -m "موقع الأكاديمية الذكية - محافظة الرمح"
git branch -M main
git remote add origin https://github.com/<اسم-الحساب>/<اسم-المستودع>.git
git push -u origin main
```

3. من المستودع: **Settings → Pages**، اختر **Source: Deploy from a branch** ثم **Branch: main / (root)** واضغط Save (تم إعدادها مسبقاً في مستودع `ramah`).
4. بعد دقيقة يصبح الرابط:

```
https://<اسم-الحساب>.github.io/<اسم-المستودع>/
```

## الحماية والأمان

الموقع ثابت (Static) على GitHub Pages، فما فيه خادم يخفي الملفات. لذلك ما ينفع "منع النسخ" منعاً حقيقياً: أي زائر يقدر يفتح كود المصدر أو يحفظ الصفحة. المطبَّق هنا إجراءات **ردع وتقليل مخاطر**:

- `protect.js`: تعطيل الزر الأيمن (مع إبقائه داخل الحقول)، واختصارات أدوات المطور (`F12`, `Ctrl+Shift+I/J/C`)، وعرض المصدر (`Ctrl+U`)، وحفظ الصفحة (`Ctrl+S`)، ومنع سحب الصور والشعار.
- **سياسة أمان المحتوى (CSP)** داخل كل صفحة: تمنع تحميل سكربتات أو أنماط من أي مصدر غير مسموح، وتغلق `object-src` وتمنع تغيير `base` — هذا يحمي الزائر من حقن أكواد خارجية.
- **SRI + crossorigin** على ملف Font Awesome من CDN: لو تغيّر الملف على الـ CDN يتوقف تحميله بدل تنفيذ كود معدّل.
- `rel="noopener noreferrer"` على كل الروابط الخارجية، و`referrer` مقيد.
- `robots.txt` يمنع زواحف الذكاء الاصطناعي (GPTBot, CCBot, ClaudeBot, Bytespider...) من سحب المحتوى، مع `sitemap.xml` للفهرسة الطبيعية.
- فتح الأقسام محمي بقائمة بيضاء (`validSections`) فلا يمكن تحميل ملفات عشوائية عبر الرابط، ورسائل الخطأ لا تُدرج نصاً في HTML.

> الحماية الكاملة (منع النسخ فعلياً) تحتاج خادماً يتحقق من الهوية قبل إرسال المحتوى، مثل تسجيل دخول ديسكورد/جوجل + API. الردع الحالي يمنع العبث العابر فقط، ولا يمنع من يفهم تقنياً.
